# Фирменный стиль Олеси

Тёплая, эстетичная палитра: бежевый, серо-бежевый, коричневый. Структура и типографика — как у maysoulme, цвета — свои.

## Цвета
- Фон страницы: `#FAF7F3` (тёплый бежево-белый)
- Текст: `#2A211C` (тёмный кофейно-коричневый)
- Второстепенный текст: `#5E534C`, `#7A6F67`, `#9A908A`
- Акцент (коричневый): `#7B5A43` — курсивные выделения в заголовках, нумерация, точки списков, бейджи, рамки результата
- Серые блоки (highlight): `#F1ECE6` — квадратные углы, без цветных линий слева
- Карточки: `#F5F1EC`, рамка `#E4DCD3`
- Советы внутри карточек: `#ECE5DD`
- Линии-разделители: `#E9E3DC`, тонкие линии навбара `#EFE9E2`
- Тёмный фон (титульные слайды, футеры при необходимости): `#2A211C`; на нём акцент — `#D9BFA4` (песочный). Коричневый `#7B5A43` на тёмном фоне НЕ использовать.

CSS-переменные (вставлять в каждый файл):
```css
:root {
  --bg: #FAF7F3; --text: #2A211C; --muted: #5E534C; --muted-2: #7A6F67; --muted-3: #9A908A;
  --accent: #7B5A43; --accent-dark: #D9BFA4;
  --block: #F1ECE6; --card: #F5F1EC; --card-border: #E4DCD3; --tip: #ECE5DD; --line: #E9E3DC; --nav-line: #EFE9E2;
}
```

## Шрифты (те же, что у maysoulme)
```html
<link href="https://fonts.googleapis.com/css2?family=Libre+Baskerville:ital,wght@0,400;0,700;1,400&family=Inter:wght@400;500;600;700;800&family=DM+Sans:ital@1&display=swap" rel="stylesheet">
```
- Заголовки: Libre Baskerville, жирный, курсивные акценты коричневым
- Текст: Inter, 17px, line-height 1.75
- Нумерация: Libre Baskerville, курсив, коричневый
- Ник в навбаре: DM Sans, italic, `#9A908A`

## Логотип и навбар
- Пока нет графического логотипа — слева в навбаре текстовая монограмма: `<span class="nav__mono">O</span>` (Libre Baskerville, italic, 22px, цвет акцента), справа — ник курсивом (DM Sans, italic, `#9A908A`).
- Ник: `[нужна деталь: ник Олеси]` — до уточнения писать `olesya`.
- Когда появится логотип — положить в `~/.claude/brand/logo-olesya.png` и заменить монограмму на `<img>` высотой 30px.

## Правила
- Квадратные углы везде (никаких border-radius, кроме круглых точек списков и точек шагов)
- Серые блоки без цветных полос слева
- На тёмном фоне акцент только `#D9BFA4`
- Слова «Claude» и «reels» — только латиницей
- Тексты для аудитории — на «ты», в женском роде

# Рабочее место Олеси — полная настройка с нуля

Этот репозиторий превращает твой Claude Code в готовую систему для блога: сценарии reels и сторис, посты и воронка в Telegram, лид-магнит, прогрев, продающий урок, гайды, презентации и карусели — всё в твоём голосе и твоей палитре. Claude уже знает, кто ты, твою историю, аудиторию и границы: ему не надо ничего объяснять заново.

Иди по шагам ПО ПОРЯДКУ. Ничего не пропускай. Если застряла — шаг 8.

---

## Шаг 0. Что у тебя будет в конце

Claude Code с 14 командами (скиллами). Каждая вызывается словом со слэшем или обычной фразой:

| Скилл | Что делает |
|---|---|
| `/reels-expert` | Сценарий экспертного reels из одной мысли — хук, тело, финальная строка, под суфлёр |
| `/reels-story` | Сценарий личного reels из твоей истории (декрет → свобода, выбор себя) без запретных тем |
| `/stories` | Сценарии сторис на день: прогрев, вовлечение, продажа — по кадрам |
| `/tg-posts` | Посты для Telegram-канала в твоём голосе: одна мысль, финал одной строкой |
| `/tg` | Режим продюсера канала: подтягивает твои прошлые посты из `~/tg-assistant`, держит стиль и план |
| `/tg-funnel` | Воронка в Telegram: путь от подписки до покупки, тексты каждого шага |
| `/lead-magnet` | Лид-магнит: идея, структура, текст (например, доработка «Разреши себе быть богатой») |
| `/ca-tripwire` | Разбор аудитории по сегментам и подбор трипваера под неё |
| `/progrev` | Прогрев к запуску: план по дням, посты, сторис, reels |
| `/selling-lesson` | Продающий урок / вебинар: структура, смыслы, переход к продаже |
| `/guide` | Гайд-лендинг или статья страницей в интернете в твоём стиле |
| `/presentation` | Презентация к видеоуроку с местом под твоё видео |
| `/presentation-full` | Полноэкранная презентация + экспорт в PDF |
| `/carousel` | Карусель для Instagram 1080×1350, готовые PNG |

Плюс:
- Папка `~/tg-assistant` — архив постов твоего канала (Claude сам его пополняет), черновики, план, мониторинг чужих каналов.
- Твой профиль, эталоны голоса и палитра — лежат в `~/.claude/brand/`, Claude читает их перед каждой задачей.
- `~/olesya-setup/content/` — твои готовые материалы (гайд, книга, планы).
- `~/olesya-setup/parser/` — инструкция по парсеру reels (ставится отдельно, не обязателен).

## Шаг 1. База: установи Claude

Если Claude Code у тебя ещё не стоит — сначала пройди гайд «Claude с нуля»:
**https://maiyamaiya19999-bit.github.io/claude-montage-skill/start.html**

Там по шагам: аккаунт, подписка Pro, установка, первый запуск, проверка. Возвращайся сюда, когда тест из того гайда сработает.

---

## Шаг 2. Заведи GitHub и получи доступ

GitHub — это место, куда Claude складывает архив постов твоего канала и где публикуются твои гайды. Для установки пакета доступ к чужим репозиториям не нужен.

1. Зайди на **github.com** → Sign up → зарегистрируйся через свою почту (бесплатно, 3 минуты)
2. Подключи GitHub к своему Claude. Открой Claude Code и отправь ему:

```
Установи GitHub CLI (gh), если его нет, и залогинь меня в GitHub через браузер. Потом проверь, что вход выполнен.
```

Claude всё сделает сам, тебе нужно один раз подтвердить вход в открывшемся браузере. Соглашайся на подтверждения, которые он попросит.

## Шаг 3. Установи всё одной командой

Отправь своему Claude это сообщение целиком:

```
Скачай архив https://maiyamaiya19999-bit.github.io/olesya-guide/downloads/olesya-full-package.zip
и распакуй его в папку ~/olesya-setup. Открой в ней файл INSTALL-FOR-CLAUDE.md
и выполни установку строго по нему. Потом отчитайся по каждому пункту.
```

Claude запросит несколько подтверждений — везде соглашайся. Он сам:
- проверит и поставит инструменты (git, gh, python3, Chrome для рендера)
- разложит все 14 скиллов по нужной папке
- положит твой профиль, эталоны голоса и палитру
- создаст папку `~/tg-assistant` для архива канала
- запишет свои постоянные правила (кто ты, как общаться, границы, стиль)
- прогонит проверки

**Он спросит две вещи для канала:** токен бота от @BotFather и юзернейм канала. Если бота ещё нет — так и скажи, он продолжит без него (это можно сделать позже, шаг 8).

В конце он выведет таблицу-отчёт. Если всё «готово» — переходи дальше.

## Шаг 4. Проверь себя: тестовое задание

Отправь Claude:

```
/reels-expert Мысль: первый пост не обязан быть шедевром — он обязан существовать.
```

Если в ответ пришёл сценарий на «ты», в женском роде, короткими фразами, с хуком в начале и одной сильной строкой в конце — всё работает. Если Claude начал спрашивать, кто ты и о чём блог, — установка не дошла до конца, смотри шаг 8.

## Шаг 5. Как пользоваться: готовые фразы под каждый скилл

Пиши Claude по-человечески. Вот рабочие формулировки — копируй и подставляй своё:

**Экспертный reels:**
```
/reels-expert Мысль: faceless — не значит невидимый, это значит свободный от чужих ожиданий. Для тех, кто боится показывать лицо.
```

**Личный reels:**
```
/reels-story Про момент, когда я поняла, что опора только во мне, и как это стало стартом блога. Без деталей про семью.
```

**Сторис на день:**
```
/stories Завтра день про «нет времени на блог». Хочу показать, как делаю контент за 15 минут с ИИ, и в конце мягко подвести к гайду «Разреши».
```

**Пост в Telegram:**
```
/tg-posts Пост про то, что разрешение — это не аффирмация, а поведение. Одна мысль, финал одной строкой.
```

**Режим продюсера канала:**
```
/tg Посмотри мои последние посты и предложи план на неделю: 2 поста про блог с ИИ, 1 про деньги, 1 личный.
```

**Воронка в Telegram:**
```
/tg-funnel Собери воронку от подписки на канал до покупки интенсива «Проявись и заработай». Вход — гайд «Разреши себе быть богатой».
```

**Лид-магнит:**
```
/lead-magnet Хочу второй лид-магнит для сегмента «веду блог, но не зарабатываю». Предложи 3 идеи и разверни лучшую.
```

**Аудитория и трипваер:**
```
/ca-tripwire Разбери сегмент «хочу начать, но боюсь» и предложи трипваер до 3 000 ₽ под него.
```

**Прогрев:**
```
/progrev Запуск интенсива через 10 дней. Составь прогрев по дням: сторис, посты, reels.
```

**Продающий урок:**
```
/selling-lesson Урок «Блог с нуля за 15 минут в день с ИИ», 40 минут, в конце продажа интенсива.
```

**Гайд-лендинг:**
```
/guide Оформи этот текст как гайд в моём стиле: [вставь текст или приложи файл]. Покажи файл.
```

**Презентация к уроку (с местом под видео):**
```
/presentation Тема «Воронка без впаривания». Вот тезисы урока: [тезисы]
```

**Презентация на весь экран + PDF:**
```
/presentation-full Тема «Как ИИ забирает рутину блога». Экспортируй в PDF.
```

**Карусель для Instagram:**
```
/carousel Тема «5 причин, почему блог есть, а денег нет». Отрендери в PNG.
```

К любому запросу можно прикладывать файлы и скрины — просто перетаскивай их в чат. Твои готовые материалы лежат в `~/olesya-setup/content/` — можно ссылаться на них: «возьми главу 3 из книги в content».

**Режим «без цензуры».** По умолчанию Claude пишет прямо, но без мата. Если нужен голос как в твоих референсах — скажи в запросе: «включи режим без цензуры».

## Шаг 6. Правила

1. **Claude знает твой профиль.** Он строит контент только из твоих фактов. Если чего-то не знает — поставит пометку `[нужна деталь]` и спросит. Не просить его «придумать цифры».
2. **Границы абсолютны.** Дети и отношения внутри семьи публично не раскрываются. Claude это знает; если вдруг проскочило — скажи «убери, это за границей», он перепишет.
3. **Стиль — закон.** Бежево-коричневая палитра, Libre Baskerville + Inter, квадратные углы. Если результат выбивается (скруглённые углы, чужие цвета) — «приведи к моему стилю по style-guide.md».
4. **Claude и reels — всегда латиницей**, reels с маленькой буквы. Твой Claude это знает.
5. **Материалы Майи не выкладывать** в открытый доступ и не пересылать. Скиллы, промпты, шаблоны — только для твоей работы.
6. **Посты в канал публикуешь ты сама.** Claude пишет черновики в `~/tg-assistant/drafts/`, а в канал отправляешь ты — так у тебя контроль над каждым словом.
7. **Парсер не обязателен.** Если Claude сам предложит «давай поставлю парсер» — только по инструкции из `~/olesya-setup/parser/` и только когда тебе это реально нужно.

## Шаг 7. Приучи Claude к себе

Установщик уже записал базовые правила. Добавь личное — отправь Claude:

```
Запомни: меня зовут Олеся, мой ник в Instagram и Telegram — [ник], общайся со мной на «ты» и по-русски.
Мой основной продукт сейчас — [название и цена]. Кодовое слово для заявок — [слово].
```

Дальше добавляй что угодно по ходу работы: «запомни, что…» — он записывает это в память. Особенно полезно сразу зафиксировать ник (он нужен для навбара в гайдах) и цены продуктов.

## Шаг 8. Если что-то не работает

| Проблема | Решение |
|---|---|
| Пакет не скачивается | Проверь интернет и повтори фразу из шага 3. Если не помогло — напиши Майе, она проверит ссылку |
| Claude спрашивает, кто я и о чём блог | Профиль не установился. Скажи: «проверь, что в ~/.claude/brand/ лежат PROFILE.md и TOV-SAMPLES.md, если нет — повтори пункт 4 из INSTALL-FOR-CLAUDE.md» |
| Скилл не находится (`/reels-expert` не срабатывает) | Скажи: «покажи список файлов в ~/.claude/commands и скопируй туда скиллы из ~/olesya-setup/skills» |
| Текст не в моём голосе | Скажи: «перечитай PROFILE.md раздел 8 и TOV-SAMPLES.md и перепиши» |
| Пишет мат, хотя не просила | «Выключи режим без цензуры» |
| `/tg` не видит посты | Нужен `config.json`. Скажи: «создай ~/tg-assistant/config.json из config.example.json» и дай токен бота и юзернейм канала. Для публичного канала без бота: «запусти scrape_history.py --channel имя_канала» |
| Карусель / PDF не рендерится | Проверь, что установлен Google Chrome. Скажи: «проверь headless Chrome и отрендери снова» |
| Гайд без моих цветов | «Перечитай ~/.claude/brand/style-guide.md и приведи к стилю» |
| Claude завис или чудит | Новый чат + опиши задачу заново. Лечит почти всё |
| Всё сломалось совсем | Скажи: «переустанови всё по INSTALL-FOR-CLAUDE.md из ~/olesya-setup» |

Остальное — к Майе.

## Как обновить пакет

Майя будет дополнять скиллы. Чтобы забрать обновления, отправь Claude:

```
Обнови мой пакет: скачай свежий архив https://maiyamaiya19999-bit.github.io/olesya-guide/downloads/olesya-full-package.zip,
распакуй в ~/olesya-setup и выполни раздел «Обновление» из INSTALL-FOR-CLAUDE.md.
Мой PROFILE.md не перезаписывай без вопроса.
```

Он обновит скиллы и стиль, а `PROFILE.md` тронет только с твоего согласия — если ты вносила туда правки, он спросит, прежде чем что-то менять. Твои посты, черновики и `config.json` при обновлении не затираются.
